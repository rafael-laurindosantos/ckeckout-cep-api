# Buscador de CEP Profissional - Módulo de Checkout

Este projeto é uma ferramenta de busca de endereços em tempo real, desenvolvida para otimizar a experiência do usuário em fluxos de checkout e cadastros logísticos. Ao digitar o CEP, o sistema consome a API ViaCEP e preenche automaticamente os campos de Rua, Bairro e Cidade.

---

## Motivação do Projeto
Com experiência prévia no setor de logística, entendo que o preenchimento manual de endereços é uma das principais fontes de erros de entrega e desistência de compra. Este módulo foi criado para:
- Eliminar erros de digitação humana.
- Agilizar o processo de finalização de pedido.
- Prover uma interface limpa e intuitiva (UX).

## Tecnologias Utilizadas
- **HTML5:** Estrutura semântica da página.
- **CSS3:** Design responsivo com Flexbox (adaptado para PC e Celular).
- **JavaScript (Vanilla):** Lógica de consumo de API assíncrona (Fetch API) e manipulação dinâmica do DOM.
- **API ViaCEP:** Serviço de busca de dados postais.

## Responsividade
O projeto foi totalmente otimizado para dispositivos móveis, garantindo que o formulário se ajuste perfeitamente a qualquer tamanho de tela, mantendo a legibilidade e facilidade de clique.

## Aprendizados
Durante o desenvolvimento deste projeto, aprofundei conhecimentos em:
1. Integração de APIs externas.
2. Tratamento de erros em requisições (ex: CEP inexistente).
3. Conceitos avançados de CSS para centralização e layout responsivo.
